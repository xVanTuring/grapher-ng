## Grapher NG 1.1.0

### 新功能
- **让 AI 帮你画图**：内置 MCP 服务，Claude Code 等 AI 助手可以新建文档、插入曲线、区域和曲面、设置参数滑块、调整视角，还能生成图片查看结果。AI 的改动可以用 ⌘Z 撤销。

  - 默认关闭；只监听本机，需要访问令牌；另有「允许 AI 修改图形」开关，关闭时 AI 只能读取和看图。

## Grapher NG 1.1.0

### What's New
- **Let an AI draw graphs for you**: a built-in MCP server lets AI assistants such as Claude Code create documents, insert curves, regions and surfaces, set parameter sliders, move the camera, and render an image to check the result. Everything the AI does can be undone with ⌘Z.
  - Turn it on in Grapher NG ▸ Settings… (⌘,); the window has ready-to-copy connection commands.
  - Off by default; listens on this Mac only and requires an access token. An "Allow AI to modify graphs" switch keeps the AI read-only (it can still look at images) while it is off.
  - See [docs/usage.md](https://github.com/xVanTuring/grapher-ng/blob/main/docs/usage.md).
