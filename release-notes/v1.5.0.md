## Grapher NG 1.5.0

### 新功能
- **分步讲解**：把一份图拆成几步，讲推导过程。每一步可以指定显示哪些图层、相机角度、参数值和要播放的参数，配上标题和讲解文字（文字里可以写 TeX 公式）。
  - 画布底部有讲解卡片：← → / 空格 / PageUp PageDown 翻页，可跳页，Esc 结束；编辑模式下可改标题和原文、记下当前视角和参数、增删挪动步骤。
  - 换步时相机和参数平滑过渡；讲解只改画面，不改图层开关，结束后自动还原。
  - 自带公式排版：分式、根号、上下标、积分、求和、可伸缩括号、重音。
  - 新增示例「曲面面积元 dS」（8 步）。
- **空间曲线末端箭头**：可以用来画向量。
- **文字格式和 AI 助手**：文字格式新增 `step` 与 `>` 讲解行；AI 接入新增 `set_lesson`、`go_to_step`，`render_image` / `render_text` 支持 `step`。
- 工具栏新增「讲解」按钮，显示菜单新增开始讲解 / 下一步 / 上一步。

### 需要注意
- 在 UniReader 等笔记里的图形块暂时还不能翻页，只显示图层自己的开关。

## Grapher NG 1.5.0

### New
- **Step-by-step lessons**: split one graph into steps to walk through a derivation. Each step sets which layers show, the camera, parameter values and which parameters play, plus a title and explanatory text (TeX formulas allowed).
  - A lesson card sits at the bottom of the canvas: ← → / Space / PageUp PageDown to turn pages, jump to any step, Esc to finish. In edit mode you can change titles and text, capture the current view and parameters, and add, move or delete steps.
  - Camera and parameters ease between steps. A lesson only changes what is drawn, never the layer switches, and everything is restored when it ends.
  - Built-in formula typesetting: fractions, roots, sub/superscripts, integrals, sums, stretchy brackets, accents.
  - New example "Surface area element dS" (8 steps).
- **Arrowheads on space curves**, handy for drawing vectors.
- **Text format and AI assistants**: the text format gains `step` and `>` lesson lines; new `set_lesson` and `go_to_step` tools; `render_image` / `render_text` accept `step`.
- A Lesson button in the toolbar, and Start Lesson / Next Step / Previous Step in the View menu.

### Please note
- Graph blocks embedded in notes (such as in UniReader) cannot turn pages yet; they only show each layer's own switch.
