## Grapher NG 1.4.0

### 改进
- **关掉所有窗口后程序不退出**：程序留在 Dock 里，再点 Dock 图标就打开欢迎窗口（或按设置新建空白图）。要退出请用 ⌘Q。
- **AI 助手**：新增 `get_text_reference` 和 `render_text`。助手可以用一行一个图层的文字描述写出图形，在 Markdown 笔记（如 UniReader）里放可转动、可拖滑块的图形块；放进笔记之前先用 `render_text` 画出来检查，错误按行号报。

### 需要注意
- **AI 接入的默认端口从 8775 改为 8776**，原来的端口和 FreeMind 冲突。没在设置里改过端口的，请把 AI 客户端里的地址改成 `http://127.0.0.1:8776/mcp`（设置窗口里有填好的片段可以直接复制）。

## Grapher NG 1.4.0

### Improvements
- **Closing every window no longer quits the app**: it stays in the Dock, and clicking the Dock icon opens the Welcome window (or a new blank graph, depending on your setting). Use ⌘Q to quit.
- **AI assistants**: new `get_text_reference` and `render_text` tools. An assistant can describe a graph in a short text format, one layer per line, and put it in a Markdown note (for example in UniReader) as a block you can rotate and drive with sliders. `render_text` draws the block first so it can be checked, with errors reported by line number.

### Please note
- **The default port for AI connections changed from 8775 to 8776**, because 8775 clashed with FreeMind. If you never changed the port in Settings, update the address in your AI client to `http://127.0.0.1:8776/mcp` (the Settings window has a ready-to-copy snippet).
