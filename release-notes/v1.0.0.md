## Grapher NG 1.0.0

Grapher NG 的第一个正式版本：macOS 原生的数学绘图工具，输入公式就能画出曲线、区域和曲面。纯 AppKit + Metal 实现，需要 macOS 14 或更高版本。

### 平面图
- 显函数、参数方程、极坐标、隐函数、不等式区域五种图型
- 参数滑块：公式里用参数，拖动滑块时图形实时重算
- 无限画布：拖动或双指滚动平移，捏合或 ⌘ + 滚动缩放；1/x、tan(x) 这类间断处会正确断开
- 鼠标悬停读数，显示最近曲线上的点、坐标和斜率

### 立体图
- 显式曲面、参数曲面、空间曲线、隐式曲面
- 平面曲线也能放进立体图，画在 z = 0 上或沿 z 方向延伸成曲面
- 拖动旋转，捏合缩放图形，⌥ + 捏合放大坐标盒

### 文件与导出
- `.grapher` 文档，双击打开；改过没存时标题下显示「已编辑」，关窗或退出时提示保存
- 导出 PNG（1× / 2× / 4×，按目标分辨率重新采样）、矢量 PDF、采样点 CSV
- 访达里能看到 `.grapher` 的缩略图；按空格预览时可以直接拖动、缩放，立体图还能旋转

### 其他
- 欢迎窗口：新建平面图 / 立体图、打开示例，列出最近打开的文档
- 自动检查更新（Grapher NG ▸ 检查更新…）
- 中英文界面，跟随系统语言

### 安装
下载 `GrapherNG-1.0.0.dmg`，打开后把 Grapher NG 拖进“应用程序”。App 已用 Developer ID 签名并经过 Apple 公证。

## Grapher NG 1.0.0

The first release of Grapher NG, a native macOS graphing app: type a formula and get curves, regions and surfaces. Built with AppKit and Metal. Requires macOS 14 or later.

### 2D graphs
- Five plot kinds: explicit functions, parametric curves, polar curves, implicit curves and inequality regions
- Parameter sliders: use a parameter in a formula and the graph redraws live as you drag
- Infinite canvas: drag or two-finger scroll to pan, pinch or ⌘-scroll to zoom; discontinuities such as 1/x and tan(x) are broken correctly
- Hover to read the nearest point on a curve, with its coordinates and slope

### 3D graphs
- Explicit surfaces, parametric surfaces, space curves and implicit surfaces
- 2D curves can be placed in 3D, either on the z = 0 plane or extruded along z into a surface
- Drag to rotate, pinch to zoom the graph, ⌥-pinch to enlarge the box

### Files and export
- `.grapher` documents open with a double-click; unsaved changes show "Edited" under the title and prompt to save on close or quit
- Export PNG (1× / 2× / 4×, re-sampled at the target resolution), vector PDF and sample points as CSV
- Finder shows thumbnails of `.grapher` files, and the Quick Look preview can be panned and zoomed (3D graphs can be rotated)

### Also
- A welcome window to start a 2D or 3D graph, open an example, or reopen a recent document
- Automatic update checks (Grapher NG ▸ Check for Updates…)
- English and Chinese interface, following the system language

### Install
Download `GrapherNG-1.0.0.dmg`, open it and drag Grapher NG into Applications. The app is signed with a Developer ID and notarized by Apple.
