## Grapher NG 1.1.1

### 改进
- 重新设计设置窗口：分组卡片、开关靠右；访问令牌默认遮住（只显示最后 4 位），可显示、拷贝、重新生成；连接 Claude Code 或其他客户端的命令合并成一个切换加一个拷贝按钮。
- 设置窗口和欢迎窗口显示时，不再默认选中某个按钮或输入框。

<!-- lang:en -->
## Grapher NG 1.1.1

### Improvements
- Redesigned the Settings window: grouped cards with switches on the right; the access token is hidden by default (only the last 4 characters show) and can be shown, copied or regenerated; the commands for Claude Code and other clients are now one switcher with a single Copy button.
- The Settings and Welcome windows no longer select a button or text field when they open.
